# Function Space Evaluations

The Evaluation feature in Function Space helps you decide whether to accept a group's business and at which price.G3 RMScan recommend pricing for guest rooms and for function space rental. If needed, the system can also combine both into one price per attendee.
Based on your Function Space setup and the group information,G3 RMScalculates the group's overall revenue and profit contribution. Based on its forecast, the system also calculates if the group displaces other business.

### Managing the Displayed Data

G3 RMShides some columns in the list of saved evaluations by default. You can change the visible columns:
- Click column filteron the right side of the column headers. A window opens that displays a list of available columns. Visible columns that are checked.
- Click the title of a visible column header to hide the column.
- Click the title of a hidden column header to display the column.
- Click outside the window to close it.
- Click any column head to sort data on that column.
- Click to Export to Excel.

### Editing Group Information

- If needed, use any combination of the Search Evaluation filters to locate a saved evaluation, and clickSearch.
- ClickActionfollowing the group evaluation to be edited.
- ClickEdit Group Info. The Group Information window opens.
- Change theGroup Name, if needed.
- Change theMaterializationstatus, if needed.
- Select a newFollow-up Date, if needed.
- TypeNotesregarding the group evaluation, if needed.
- Enter theRate Contractedto record the final rate at which the group was accepted.
- ClickSave.
