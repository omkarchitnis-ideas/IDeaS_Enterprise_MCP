## Exporting and Printing Reports

G3 RMSprovides options for displaying reports on screen or in an exported Excel spreadsheet. If you select the Excel option, you can 
 download the report to a spreadsheet. You can then save or print the downloaded file.
- Click, thenReports, and then the desired report name from the menu.
- Select the desired filters.
- For the reports where the options 
	 is available, select anOn ScreenorExcelformat:On Screen: The results display as a PDF file.Excel: The results export directly to an Excel spreadsheet. Note that if you select a large date range for some reports, for example, the Data Extract,G3 RMSemails you the report. This allows you to continue to work in the system.
- On Screen: The results display as a PDF file.
- Excel: The results export directly to an Excel spreadsheet. Note that if you select a large date range for some reports, for example, the Data Extract,G3 RMSemails you the report. This allows you to continue to work in the system.
- ClickGenerate.
If you have the permissions, you  also see buttons toScheduleandSavereports.
