# Competitor Details

Use Competitor Details to view the most recent publicly available data from all competitors and all channels.
G3 RMSdisplays new rate shopping data immediately, but it impacts decisions and the forecast only after the nextprocessing(or if you run a What If scenario). SeeImportant Datesfor the most recent rate shopping data.

## Steps to Access

- Clickand thenPricing.
- Change theFromandToselections to locate the date to be viewed.
- Click theCompetitorslink. Competitor Details displays.

## Data Details

Change the default settings forProduct,Competitor,Channel,Competitive Room Typeand, if applicable,Length of Stay. For example, you may want to see the prices of only one competitor and all channels.
Click any column header to sort the table by that data element. Click the export iconto export the displayed data to a spreadsheet.
