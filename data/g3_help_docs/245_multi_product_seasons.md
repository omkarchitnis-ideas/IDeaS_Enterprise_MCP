# Multi-Product  Seasons

Use Multi-Product Seasons to create and manage Seasons across multiple products at the same time. For example, if you have multiple products that share the same seasonal date range, create the Season once and apply it to the applicable products instead of setting up each product separately. This helps keep the Season configurations consistent across related products.
