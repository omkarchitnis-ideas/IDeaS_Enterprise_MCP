# Shared Physical Rooms

Complete the Shared Physical Rooms setup step if you have physical room types where some form part of a component room and others do not. For example, your physical room type 1 KING has a capacity of 10 rooms. 5 are a part of the component room KSUITE, but the other 5 aren't. In this case, you need to tellG3 RMSwhich room numbers for    1 KING are part of the  component room KSUITE.
This way, whenG3 RMSsees the room number in a reservation for 1 KING, it knows if that reservation reduces the available capacity of the KSUITE component room. SeeComponent Rooms Reservation Practicesfor how to best manage such reservations.
Note: Before you start this setup, which requires aComponent Roomssubscription, review theOverviewto understand how they system works with component rooms.
