Use the Definition tab todescribe key characteristics of a product. For example, you can:
- Change the name of the primary priced product so it matches yours.

- Select if a Linked Product is optimized and priced byG3 RMS.

- Define what rate shopping data to use for an Independently Priced Product.
Define what rate shopping data to use for an Independently Priced Product.
- Define the number of rooms required for a guest to purchase the Group Product
Define the number of rooms required for a guest to purchase the Group Product

#### Deactivated Linked Products

If you change the Definition for a linked product that is the Base Product for other products,G3 RMSdeactivates its children (any products that are priced off that Base Product). Review the Definition for those products to ensure they are still accurate before reactivating them.

## Setup Steps to Define Products

- Click, thenDecisions, and thenPricing Configuration.
- Select an action:If enabled, click to adda new linked, group, or independent product.Click to changean existing product.
- If enabled, click to adda new linked, group, or independent product.
- Click to changean existing product.
- Complete all fields to define the product, seeData Details.
- For linked or group products, clickNextto set upDefault pricing. The Definition settings save automatically.
- For the primary pricedand any independently pricedproduct, clickSave.
