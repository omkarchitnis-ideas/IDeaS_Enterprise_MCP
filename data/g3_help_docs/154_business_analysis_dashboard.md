# Business Analysis Dashboard

The Business Analysis dashboard helps you monitorG3 RMS. You get a daily view of key business data and the system's forecasts and decisions. You can also drill down for more details and use links to pages where you can, if necessary, make changes to the forecast and decisions.

### What Questions Do You Have about the Business Analysis Dashboard?

- Where can I monitor key performance data, forecasts, and decisions for each day of the month? View theSummarytab.
- How do I view metrics at a more detailed level, by Forecast Group, Room Class and Business View? View theData Detailstab.
- How do I compare booking pace to last year? View thePace Datatab.

### Viewing Data

#### View by Inventory Group

If you set upInventory Groups, you can select one to see the data only for its defined Room Classes. The default selection is Property, or all Room Classes. You can change the default selection inPreferences.

#### Remove Excluded Segments

Select theRemove Excluded Segmentscheckbox if you want the metrics to exclude business from specific market segments. This option is available if you defined the excluded market segments inProperty Information. And if you use Inventory Groups, you must select the Property level.
