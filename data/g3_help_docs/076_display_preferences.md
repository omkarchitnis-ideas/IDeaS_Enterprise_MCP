# Display Preferences

Use Display Preferences to make selecting Room Classes easier on pages outside the Rooms Setup. You can set the order in which your Room Classes display throughoutG3 RMS, like inDemand and Wash Management. For example, if the Room Classes you view most often are some of your higher priced ones, you can change the display order for those Room Classes to be positioned right below the property level.
The Room Class on the bottom of the tower displays first in lists and menus on other pages. The Room Class on the top of the tower displays last.
Note: if you useAdvanced Price Ranking, you must use Display Preferences to create a linear display order.
Display Preferences is the final step to complete in Rooms Setup. For a summary of all the steps in Rooms setup and the importance of completing them together, seeRooms Configuration Overview.

## Setup Steps

- ClickNextafter you complete Minimum Price Differential setup. The Display Preferences step displays.
- Select theUse same order as Price Rankingcheckbox if you want Room Classes to display in the same order as Price Ranking. This option is not available if you set up Advanced Price Ranking.
- Click the upor down arrowfor any Room Class to adjust its display position. Your changes save automatically.
- ClickDone. The Rooms Setup confirmation page displays, with any changed Rooms setup steps flagged as Updated.
