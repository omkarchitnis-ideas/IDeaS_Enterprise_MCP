# Inventory Groups

Use Inventory Groups to viewG3 RMSdata by groupings of Room Classes. For example, combine several Room Classes with different types of suites into one All Suites Inventory Group, then view its performance data  on reports and dashboards, likeBusiness Analysis.
Use theAuto Createbutton to set up one Inventory Group for each Room Class. That helps you view data at Room Class level wherever property level data is the only option. Define a default Inventory Group inPreferences. For more information, viewbest practices for Inventory Groups.

## Setup Steps

### Auto Create Inventory Groups for Each Room Class

- Click, thenExternal Data, and thenBusiness Views.
- Click theInventory Groupstab.
- ClickAuto Create.Note: you can use this option only once and only if you have more than  one Room Class.
- ClickContinue.G3 RMScreates one Inventory Group for each Room Class and  displays them in the left pane. The system will update the Inventory Group if you change Room Classes.
- If needed, click the arrowsto change theDisplay Order.This saves you time if you have many Inventory Groups and always select a specific one when viewing data.

### Add Other Inventory Groups

If needed, add  other Inventory Groups, for example, because you havemixed inventories.
- Enter a groupName.
- Enter an optionalDescription. It is used only for informational purposes.
- Select theAvailable Room Classesto be added to the new Inventory Group. ### Change or Delete Inventory Groups

- To edit an Inventory Group, select it in the left pane and make the necessary changes on the right side.
- To delete an Inventory Group, click the delete icon, then clickYesto confirm the deletion.
