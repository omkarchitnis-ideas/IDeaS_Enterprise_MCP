# Delphi Integration

This topic provides an overview of the data integration betweenG3 RMSand the Delphi sales and catering system. Once it's set up, you can start a booking evaluation from your Delphi system. The integration completes the evaluation details inG3 RMSwith the information from Delphi, so you don't need to enter booking info in two systems. After you generate and save the evaluation inG3 RMS, its result is sent back to your Delphi system. The integration is available forGroup PricingorFunction Spaceevaluations.

## Steps

### Setup

Complete either theGroup PricingorFunction Spacesetup steps.
The revenue streams in theConference & Banquet tab are completed for you, based on the Delphi setup.

### Running an Evaluation

- In your Delphi system, select the booking you want to evaluate. ClickEvaluate Booking
- If you are signed in toG3 RMS, theNew Evaluationpage opens.
- Review and, if necessary, complete the fields. SeeData Detailsbelow for how the fields align between the two systems. SeeGroup EvaluationsorFunction Space Evaluationsfor details on theG3 RMSsteps and fields.If you use a temporaryUndecided(or To Be Assigned, TBA) function room, you must replace it with a specific room.
- ClickGenerate Evaluation.
- Once the results display, clickSave Evaluation. The results are sent back to your Delphi system. You can find them in the booking as an open activity called "Evaluation Results."
