# Fiscal Calendar

If your financial reporting period doesn't follow the standard twelve-month calendar, use Fiscal Calendar 
 to set up a non-standard, twelve-period calendar. To use the 
 Fiscal Calendar, first enable it inPreferences.
The twelve periods control the data displayed on these pages:
- At 
 a Glance Dashboard
- Business Analysis Dashboard:Summary,Data Details, andPace Data
- Budgetmodule start and end dates for the selected month
- My Forecastmodule start and end dates for the selected month

### Last Year's Data

G3 RMScompares the displayed period this year to exactly the same period last year, regardless of last year's fiscal calendar setup.

## Setup Steps

- Click, thenProperty, and thenFiscal Calendar.
- Select theYearfor which you want to set up the twelve periods. You can set up one year at a time.
- ClickRetrieve. The standard calendar months display as the default for the year.
