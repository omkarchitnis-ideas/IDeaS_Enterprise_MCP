# Group Pricing Configuration

Use Group Pricing Configuration to informG3 RMSabout the range of prices, costs, and group revenue streams in a group evaluation. This setup is required before you can run an evaluation and it influences the results of a group evaluation, like the recommended rate, the net profit and the displacement.

## Setup Steps

Which steps do you want to learn about:
- Complete the setup of Base Room Type and Offsets inPricing.
- Define a range of prices for each Base Room Type inCeiling/Floor.
- Add your property's per roomServicing Costby Room Class, used to calculate the Gross Profit and Displaced Profit values.
- Define theConference & Banquetrevenue streams and their profit percentage, like meeting room rental or banquet food and beverage.
- Define theAncillaryrevenue streams generated by transient and group guests, like restaurant, golf, spa and entertainment.
- TellG3 RMSwhichRoom Typesyou want to use in group pricing evaluations.
- Set up an optionalMinimum Profit Percentageto define a profit value that groups must meet when you evaluate them.
- IfG3 RMSintegrates with your sales and catering system (like Delphi):
- Map theGuest Room Typesbetween the systems.
- Map theMarket Segmentsbetween the systems.
- If your property prices groups per attendee, also called Daily Delegate pricing, define thePackagesetup.
- If your property has aDelphi integration, use theGroup Statustab to define the behavior of the Delphi codes.
