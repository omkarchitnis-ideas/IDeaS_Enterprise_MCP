# Blended Price

Use the Blended Price window if you want the price of anindependent productto remain the same. For example, some clients with extended stay products use this for their monthly price because their guests don't expect the price to change daily during their stay.

## Steps to Set Up  Blended Price

- Click, thenDecisions, and thenPricing.
- Click Advanced Settings.
- ClickBlended Price.
- Select theProduct.
- Select theFrequency:SelectNoneto define a one-time Start and End Date. Create additional periods with other start and end dates.SelectWeeklyto use a recurring pattern starting on a defined day of week (DOW) and date.SelectMonthlyto use a recurring pattern for a full month with a defined Start Date.For a Monthly example, select the first of the month andG3 RMSkeeps the price of the selected product the same during each month and updates the price at the end of each month.
