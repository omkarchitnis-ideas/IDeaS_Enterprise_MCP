# Preferences

Use the Preferences feature to select your preference for how you want 
 to view data.

## Set Your Preferences

- Click your initials in the top right corner of the page, and thenPreferences.The Preferences window displays.
- Next to your user name, select yourViewing Preference, 
	 Tabular View   
	 or Calendar View. This is the default 
	 view for the Pricing page.
- Select theDefault Propertyto display when you first log on.
- If you createdProperty 
	 Groups, select theDefault Property 
	 Groupthat displays.
- Select theDefault 
	 Landing Page. The landing page is the first page that displays 
	 after you log on. We recommend that you select Information Manager to be aware of system Alerts.
- In theMulti Property Screen 
	 Defaultsetting, choose whether the Property or Group view 
	 will be your default display when you log on. This setting controls 
	 the default view forInformation 
	 Managerand theAt 
	 a Glancedashboard. SeeProperty 
	 Groupsfor more information.
- If enabled, select theDefault Inventory Group.  SeeInventory Groupsfor details.
- To use a fiscal calendaron At a Glance, the Business Analysis Dashboard, and the Budget module, select theUse Fiscal Calendarcheckbox. Then,define your fiscal periods inFiscal Calendar.
- ClickChange Personal Settingsfor user-specific options like preferred language, changing your password, or using Multi-Factor Authentication. The My Profile page opens.
- Make changes on thePersonal DetailsorSecuritytabs. For details about those tabs, click the Help icon?on that page.
- ClickBackto return to the Preferences page.
- ClickSave.
