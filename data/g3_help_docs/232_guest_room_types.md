# Guest Room Types

Use Guest Room Types to map the room types from your sales and catering system (like Delphi) to the room types inG3 RMS. If you subscribe to the integration of the two systems, this ensure that the group booking data from the sales and catering system is sent to the correct fields in theG3 RMSGroup Pricing Evaluation screen.

## Setup Steps

- Click, thenDecisions, and thenGroup Pricing Configuration.
- ClickGuest Room Type. All room types from your sales and catering system display asSales and Catering Room Types.
- For eachSales and Catering Room Type, select aG3 RMSroom type from theMap to RMS Room Typemenu on the right.
- ClickSave.

## Best Practices

### Map All Guest Room Types

You must map all sales and catering room types before you can start an evaluation in your sales and catering system.If needed, the system alerts you that there is anUnassigned Function Space Room Type. 
If you remap room types, you cannot run an evaluation until the next optimization completes.
Multiple Sales & Catering Room Types can be mapped to the same RMS Room Type. However, each Sales & Catering Room Type can only be mapped to one RMS Room Type.
