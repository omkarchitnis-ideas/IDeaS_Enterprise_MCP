# Saved Reports

Use this page to generate reports for which you saved a version with specific criteria. For example, every day you run a Pick Up/Change report with the changes  since last night's processing and for the next 14 days. Instead of selecting the same options every day, you save that version so you can quickly generate it from this page.
Note: Your saved reports are only available for the property that you saved it for, but your saved reports are available for others at the same property.
