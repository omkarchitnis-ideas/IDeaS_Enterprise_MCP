# Rate Plan Production Report

Generate orschedulethe Rate Plan Production report to view aPick Up or Change reportthat shows the productivity of selected rate plans. You can select up to 25 rate plans at a time.

## Reporting Steps

- Click, thenReports, and thenRate Plan Production.
- Select the desired report style.ThePick 
	 Up Reportshows the pickup activity for occupancy, revenue, and ADR on books. It measures activity  from one nightly optimization to another nightly optimization.TheChange Reportcompares data from a past processing to the current for occupancy, revenue, and ADR on books. You select an Analysis date range, and then select an Activity date from which you want to see cumulative change for each day of arrival. You can then compare the current values for each day of arrival to the change that took place from your selected activity date to the current date.
