## Override Steps

- Clickand thenOverbooking.The Overbooking Management calendar displays the overbooking decision and the occupancy forecast. Learn how tochange your calendar view.
- Navigate to the month in the calendar view that contains the dates for the override.
- ClickMultiday Overrides.The Multiday Overrides window displays.
- Select theStart DateandEnd Datefor the override. Your date range selection is limited to the two months that are visible on the calendar.
- Select the days of the week to which you want to add or remove overrides.
- Select an overbooking type and enter the number of rooms that the system is allowed to overbook for the property or the room type:Ceiling: Set the maximum number of rooms thatG3 RMScan overbook for the period. This type of override still allows the system to optimize the overbooking decision within the upper limit.Value: Overbook by a specific number of rooms for the period at the property level. This type of override limitsG3 RMSto use that value instead of  its own optimized decision, until you change or remove the override.No Ceiling:G3 RMSoptimizes the overall property or room type overbooking for the period.
- Ceiling: Set the maximum number of rooms thatG3 RMScan overbook for the period. This type of override still allows the system to optimize the overbooking decision within the upper limit.
- Value: Overbook by a specific number of rooms for the period at the property level. This type of override limitsG3 RMSto use that value instead of  its own optimized decision, until you change or remove the override.
- No Ceiling:G3 RMSoptimizes the overall property or room type overbooking for the period.
- Click the notes iconto explain why you enter the override. This helps during your regular reviews of your overrides. This iconindicates that a note exists.
- ClickApply. The unsaved changes iconin the calendar indicate dates with overrides that you must save or cancel.
- ClickWhat Ifto see the impact of your override. SeeWhat Iffor details.
- ClickSaveto finalize the multiday overrides.Override icons (depending on the type:,or) replace the unsaved changes icons. The impact on the forecast and other decisions is calculated and sent to yourselling systemin the nextProcessing.
To limit overbooking, we recommend that you apply Ceiling instead of Value overbooking overrides whenever possible to allowG3 RMSto adjust its decision as the conditions change, for example when the system expects less wash as the override date approaches.
- Enter a new cost of walk value for a room type in theUsercolumn.
- ClickApply. The unsaved changes iconin the calendar indicate dates with overrides that you must save or cancel. The What If and Save buttons become enabled.
- ClickWhat Ifto see the results of your override before saving. For more information, seeWhat If.
- ClickSaveto finalize the overrides. The impact on forecasts and other decisions is not calculated until the next optimization cycle. Changes to decisions are sent to your selling systems in the next optimization.
To see what level the override applies  to, use theBusiness Analysis Dashboardorchange your calendar viewon Overbooking Management.
- In theActioncolumn for the property or room type row where the override exists, click the remove icon.
- ClickApply. The unsaved changes iconin the calendar indicates the dates where you want to remove overrides.
- ClickWhat Ifto test the impact of removing the override. SeeWhat Iffor details.
- ClickSaveto finalize the override removal. The icons are removed.
