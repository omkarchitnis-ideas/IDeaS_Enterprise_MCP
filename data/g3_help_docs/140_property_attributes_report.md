# Property Attributes Report

Use the Property Attributes Report to get an overview of all property attributes at once, especially if you manage this setup for multiple properties. It gives you a consolidated view of the Property Attributes assignments for all the properties that are available to you.

## Reporting Steps

- Click, thenReports, and thenProperty Attributes.The Setup pane displays.
- Select aReport Format:On Screen: The results display in the bottom pane.  Click the export iconto export the displayed results to a spreadsheet.Excel: The results export directly to an Excel spreadsheet.   If you select the Excel option after results are displayed on the screen, the screen will clear, and the exported spreadsheet will reflect your current filter selections.
- On Screen: The results display in the bottom pane.  Click the export iconto export the displayed results to a spreadsheet.
- Excel: The results export directly to an Excel spreadsheet.   If you select the Excel option after results are displayed on the screen, the screen will clear, and the exported spreadsheet will reflect your current filter selections.
- ClickGenerate.
SeeExporting and Printing Reportsfor more information about managing report downloads 
		in your browser.
