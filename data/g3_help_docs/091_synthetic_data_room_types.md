## Setup Steps

- Click, thenForecasts, and thenSynthetic Data.
- In theRoom Typetab, click the add iconto open a row for a new room type.
- Enter theCodefor the room type. Each room type code must be unique.
- Enter theNamefor the room type.
- Enter an optionalDescription.
- Enter theCapacityfor the room type.
- Click the save icon.
Click the edit iconto make changes to the room type data, or click the delete iconto remove a room type.
