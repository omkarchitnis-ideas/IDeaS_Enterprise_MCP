# Age Based Pricing

If you selected custom Child Pricing Type on theDefinitiontab, use Age Based Pricing to define specific pricing by child age. This allows you to define a specific pricing strategy for each of your products.

## Setup Steps

### Accessing Age Based Pricing

- Click, thenDecisions, and thenPricing.
- Select an action:Click to adda new product.Click to editan existing product.
- Click to adda new product.
- Click to editan existing product.
- ClickNextafter completing the product'sDefinition.
- ClickNextafter completing the product'sDefaultsettings.
- ClickNextafter completingSeasons, if needed. The Age Based Pricing tab opens.

### Setting up Age Based Pricing

If you selectedCustom for ProductChild Pricing Type on the Definition tab, set up  how the product's age based prices are adjusted from the Base Product. Otherwise, this is a view only tab.
- For each room type and occupancy type in a Room Class, select anOffset Method:Fixed:G3 RMSadds the offset value to the Base Product price.Percentage:G3 RMScalculates the offset as a percentage of the Base Product price.
- Fixed:G3 RMSadds the offset value to the Base Product price.
- Percentage:G3 RMScalculates the offset as a percentage of the Base Product price.
- Enter the offset value for each room type, occupancy type and day of the week:Enter the offset value in the first field. The value populates each day of the week.Press theTabkey to navigate to a day of the week to edit the value, if needed.
- Enter the offset value in the first field. The value populates each day of the week.
- Press theTabkey to navigate to a day of the week to edit the value, if needed.
- ClickSave.
- ClickNextto set up any requiredRestrictionsfor the product.

### Setting up Age Based Pricing by Season

After you define the default values for the product, you can create optional seasons that override the defaults.
- In the Seasons pane, click to adda season.
- Add aName. You can refer to this name later if you need to copy a season to create another.
- Enter or select theStart Datefor the season. The Start Date must be greater than or equal to theSystem DateDisplaying in the top right of each G3 RMS page, it's the time when  the RMS last received data from your reservation system. If the data is late, you get an Alert..
- Enter or select theEnd Datefor the season. The End Date can be any future date and is not limited by the forecast window.
- Enter the offset value for any room type, occupancy type and day of the week that differs from the defaults. Leave those fields empty that are the same as the default.
