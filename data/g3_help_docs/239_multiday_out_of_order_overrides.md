# Multiday Out of Order Overrides

Use Multiday Out of Order Overrides to  giveG3 RMSthe correct out of order information when it should ignore that information from yourReservation SystemThe primary reservation system, like a PMS or CRS, that provides data to the RMS%]. The data from that one system is used by the RMS to forecast, optimize and produce controls. The controls are sent to all selling systems, which for some integrations may exclude the reservation system.. ReviewOut of Order Overridesfor when that applies.

## Override Steps

- Clickand thenOut of Order Overrides.
- If necessary, use theFrom,To, andDay of Weekfilters to change the date range and the days of the week for which you want to add or change
	 multiday overrides.
- ClickMultiday Override.
- Enter the value in theOverridecolumn for each room type. Select theDeletecheckbox to remove an override for a room type.
- ClickApply.
- Unsaved changes are highlighted in yellow. Click theicon to revert the changes for a day. ClickCancelto revert all changes.
- ClickSaveto make your changes final.
