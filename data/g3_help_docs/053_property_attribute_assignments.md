# Property Attribute Assignments

AfteryoucreateProperty Attributes, use the Property Attribute Assignments page to map the attributes to each property. You can change or remove attributes for a single property or for multiple properties at once.

## Setup Steps

### Assigning Property Attributes

- Click, thenProperty, and thenProperty Attributes Assignments.
- Select aProperty Name.
- For each Property Attribute, select or type a value, depending on the type of field.
- To remove a Property Attribute value, click  the delete icon.
- ClickSave.
