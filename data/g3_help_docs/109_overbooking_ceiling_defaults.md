# Overbooking Ceiling Defaults

Use Ceiling Defaults to set a maximum overbooking amount by day of week at the property or room type level. Ceiling Defaults have no end date, meaning that, for example,  a Ceiling Default for Monday applies toallfuture Mondays. Seebest practicesfor when Ceiling Defaults do not apply.
