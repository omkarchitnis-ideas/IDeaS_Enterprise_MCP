# Business Analysis Data Details

Use the Data Details tab to review data in more detail than on the Summary tab, for example, the total rooms on books and the pickup for the next 14 days by rate code or by room type.G3 RMSsummarizes the data for your selected dates grouped by Forecast Group, Room Class, or Business Views. If you want to view values for a single date, adjust the slider to that date only.

## Data Details

All comparisons to the data of past years are for the same days of the week, not the same calendar dates. For example, if you select Monday, April 1 to Sunday, April 7,G3 RMScompares the data to the previous April for Monday, April 2 to Sunday, April 8.
Not all data points display down to the most detailed business level. Here are some examples:
- Occupancy ForecastThe number of rooms (or percentage of the total number of rooms) that the RMS expects the property to achieve for the period. 
For the calculation, see the Demand and Wash - Overview topic (under Data Details).displays down to the room type level, but not to the rate code level.
- Remaining unconstrained demand displays down to the Forecast Group and Room Class level, but is not available for Business Views.
