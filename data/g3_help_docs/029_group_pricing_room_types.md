# Group Pricing Room Types

Use this page to define which Room Types  are available in an evaluation and to exclude room types that should never be used in an evaluation. For example, you might not include room types that belong to aPrice ExcludedRoom Class. Thatâs becauseG3 RMSdoesnât calculate the Recommended Rate for such room types and instead uses the fixed priced that you defined.
The Room Type setup applies only to evaluations using the Room Class method, not the Run-of-House method.

## Setup Steps

### Accessing the Room Type Page

- Click, thenDecisions, and thenGroup Pricing Configuration.
- Click theRoom Typetab.
In the initial setupG3 RMSautomatically selects all Room Types that areIncluded in ROH Evaluations. You review the Room Types and, if needed, remove any to ensure that it meets your property's needs.

### Adding Room Types

- Select the appropriate room types from theAvailable Room Typeslist:
- Filter the room types by typing a string of characters from its name in theSearchfield.
- PressCtrl+ click to select multiple room types in the list.
- Click>to add selected room types or click>>to add all room types to the Selected Room Types list.
- ClickSave.

### Editing Room Types

If you remove a room type you can still view the results of saved evaluations that use that removed  room type. But if you want to re-evaluate the group, you  must first change the room type.
- Select the appropriate room types from theSelected Room Typeslist:
- Filter the room types by typing a string of characters from its name in theSearchfield.
- PressCtrl+ click to select multiple room types in the list.
- Click<to remove selected room types or click<<to remove all room types from the Selected Room Types list.
- ClickSave.
