# Input Override Report

Use the Input Output report to ensure that existing overrides remain relevant and helpG3 RMSproduce the best possible forecasts and decisions. Generate orschedulethe report weekly, together with theOutput Override report, and use them to review your input overrides (Demand-Occupancy Date,Demand-Arrival by LOS, andWash) and all other overrides.
Alternatively, you can see all overrides on theBusiness Analysis dashboardand on pages like Demand and Wash Management, you can filterto highlight dates with overrides.
Note: Cost of Walk overrides are inputs but are on the output report because you set them in Overbooking Management.
