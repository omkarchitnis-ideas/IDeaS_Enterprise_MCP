# Select Component Rooms

Use the Select Component Rooms setup to tellG3 RMSwhich room types represent your component room types.
In the initial setup, the left side of the page displays all room types with a capacity of zero, imported from thereservation system. Move those that are component room types  to the right side and leave any pseudo or paymaster room types on the left side. In an existing property, aNew Component Room TypeAlert tells you when you might have to update this setup.
Note: Before you start this setup, which requires a Component Rooms subscription, review theOverviewto understand how the system works with component rooms.

## Steps to Select Component Room Types

- Click, thenInventory, and thenComponent Rooms.
- ClickNextafter reviewing the introduction. The Select Component Rooms step displays.
- If needed, use theSearchfield above the left pane to find the appropriate room type codes. Enter a character string in the field to filter the list.
- In the left pane, select the room type codes that represent component rooms. Press Ctrl+click to select multiple room types or Shift+click to select a range of room types.
- Click>to move the 
	 selected room types to the Component Room Type pane. Click>>to add all room types, regardless of your selection.
- Your changes are automatically saved when you clickNext. Continue to complete all the steps in Component Rooms setup.

### Removing Component Room Types

If room types that you moved to the right pane do not represent component rooms:
- Select the room type codes and click<to move them back to the left pane.
- Click<<to move all room types back to the left pane.

## Best Practices

### Select Unique Room Types

Component Rooms must have unique room type codes. The same room type code cannot be used for both a physical room and a component room type.

### Select At Least One Room Type

You must select at least one room type as a component room type to proceed with the Component Rooms setup. If any of your component room types are missing, it might be an integration issue. Contact your IDeaS representative.
