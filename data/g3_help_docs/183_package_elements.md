# Package Elements

Use Package Elements if any of your linked products include non-room elements, such asbreakfast. Once set up,youcan apply the package elements to products in theDefinitiontab. See how the systemprices linkedproductsabout the impact of package elements.

### When Not to Set up Packages

Do not add packages that are already part of the Base Productâs final price.For example, a linked product includes breakfast, but you already added breakfast to the Final Price of your Base Product usingSupplements. In this case, you do not need to set up breakfast as a package element.
Only set up packages used in Linked Products. You don't need to set up every package from yourreservation system.
