# Data Retention

G3 RMSautomatically deletes data that falls outside the time frames of the following retention policy:

## Historical Data

G3 RMSkeeps:
- Summary pace data for two years.
Summary pace data for two years.
- Transactional pace data for three years.
Transactional pace data for three years.
- Summary data and transactional data for three years.
Summary data and transactional data for three years.

## Configuration Settings

G3 RMSuses the current values in configuration settings to generate its forecasts 
 and decisions and only saves the current settings. If you set up seasons,G3 RMSdeletes past seasons where the end date is more than 365 days in the past.

## Decisions

G3 RMSdoes not need to retain this data for its 
 analytical processes.
- Decision 
	 pace (Last Room Value, pricing, Occupancy Forecast, 
	 and overbooking) is kept for one year.
- Decisions are kept for one year.
