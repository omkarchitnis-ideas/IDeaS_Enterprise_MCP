# Best Practices for Comparing Pace Data

## Limit the Number of Data Points

If you compare more than a handful of data points, each with a pace curve for current, past year and forecast, the graph may look confusing. To hide any of the curves, click its colored square icon in the legend below the chart.

## Compare Pace Against STLY as an Indication

Comparing actual pick-up against the expected pace is a significant factor whenthe RMSforecasts demand. Thus, seeing when the system expects the remaining demand to book can help you understand the forecast. For example, if the expected booking pace differs greatly from the Occupancy On Books STLY, thenthe RMSlikely found that the more recent pace is a better fit for the forecast than past yearâs pace.
Note: Use the STLY comparison only as an indication, because for the expected pace, the system uses all available data, not just last year's. Learn more abouthowthe RMSforecasts demand.
