# Data Quality

Available withRate Data Advantage, use the Data Quality tab to look for any issues with the publicly available rate shopping data. This page is only informational; IDeaS resolves any issues. You get an Alert if you need to resolve any issue, like mapping a new rate shopping room type.
Colors represent the severity of issues:
- Green: no issues, all is well.
Green: no issues, all is well.
- Yellow: IDeaS is investigating an issue andG3 RMSstopped using the prices data from the impacted rate shopping results. After the issue is resolved, the system resumes using the most recent data.
Yellow: IDeaS is investigating an issue andG3 RMSstopped using the prices data from the impacted rate shopping results. After the issue is resolved, the system resumes using the most recent data.
