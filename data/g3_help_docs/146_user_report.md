# User Report

Generate the User report to audit yourG3 RMSusers and their permissions. You can filter by property or Property Group, by Role, or specific users. The list shows the selected users, their user status, and their last login.

## Reporting Steps

- Click, thenReports, and thenUser Report.The 
	 Setup pane displays.
- Use theUser Associationfilters in the Properties, Authorization Groups, User Roles, or User Names columns to locate the desired user accounts:
- Select multiple items in the same filter column to expand your results. For example, if you select Property A and Property B in the Properties filter, your results include all users with access to Property AorProperty B.
- Select items in different filter columns to narrow your results. For example, if you select Property A and Property B in the Properties filter and select Admin in the User Role filter, your results include  users with access to Property AorProperty Bandare assigned to the Admin role.
- Filter the list of available items in each column by entering a string 
		 of characters in theFindfield.
- Select theAllcheckbox to include all items available in that filter column.
- Click an item in the filter column to find user results only for that item. Press Ctrl + click on 
		 multiple items to filter for users that apply to each selected item.
- Select the users'Status:
- Any: The results 
		 display all Active and Inactive users who meet the selection criteria 
		 defined in the filters.
- Inactive: The results 
		 display all users who have been deactivated and who 
		 also meet the selection criteria defined in the filters. Inactive users cannot sign in toG3 RMS.
- Active: The results 
		 display all users with a status of Active who also meet the 
		 selection criteria defined in the filters.
- Select aReport Format:On Screen: The results display in the lower pane.  Click the export iconto export the displayed results to a spreadsheet.Excel: The results export to an Excel spreadsheet. If you select this option after results are displayed on the page, the page clears, and the exported spreadsheet reflects your current filter selections.
- On Screen: The results display in the lower pane.  Click the export iconto export the displayed results to a spreadsheet.
- Excel: The results export to an Excel spreadsheet. If you select this option after results are displayed on the page, the page clears, and the exported spreadsheet reflects your current filter selections.
- ClickGenerate.
SeeExporting and Printing Reportsfor more information about managing report downloads 
		in your browser.

### Viewing User Details

The User Details window provides additional details about the user in an Authorization Group or an individual property view. If you export your results to an Excel spreadsheet, user details are also included in the exported data.
- Click the magnifying glass iconto display more details about the user.
- Choose how you want to view the user data:SelectAuthorization Groupto view the Authorization Group to which the user is assigned.SelectIndividual Propertiesto view the individual properties to which the user has access.
- SelectAuthorization Groupto view the Authorization Group to which the user is assigned.
- SelectIndividual Propertiesto view the individual properties to which the user has access.
